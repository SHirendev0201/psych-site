MINDCHECK
Extract this ZIP into one folder.
Install Node.js LTS on Windows if needed. The Node.js backend source and npm
dependency lockfile are included. Install dependencies with npm.cmd ci.
Double-click START.cmd and open http://localhost:3000.
Frontend files are in public/. Save and refresh to see edits.
For database quizzes copy .env.example to .env, enter your MySQL settings,
and start your existing psych_site database. Restart after changing .env.
The therapist panel uses a pending-profile notice because actual therapist
names, qualifications, contact details and prices have not been supplied.
Edit public/therapist.js to insert confirmed information.
Results are currently stored in the browser. Database credentials are local.
